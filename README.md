# INKFLUX
Agent 001 endless run

A Temple Run-style 3D runner built with Three.js in a single HTML file. Agent 001 sprints through three timelines, linked by dimensional portals:

1. **Primeval Jungle**: ancient stone path, palms, waterfalls, brachiosaurus, pterodactyls and a lightning volcano
2. **NEO-KYO 3091**: rooftop run above the clouds with gaps, laser fences and hologram barriers
3. **Crystal Expanse**: a glowing bridge through a nebula, with floating crystal islands

Collect Purple Gems, cross rifts and survive as the speed climbs.

## Play

Open `index.html` in a browser, or serve the folder with any static host (GitHub Pages works). It needs no build step. Three.js r128 and the fonts load from public CDNs.

| Action | Keyboard | Touch |
| --- | --- | --- |
| Switch lane | ← → or A / D | Swipe left / right |
| Jump | ↑, W or Space | Swipe up or tap |
| Slide | ↓ or S | Swipe down |
| Pause | P or Esc | |
